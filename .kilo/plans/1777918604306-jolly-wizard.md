# Drag and Drop Not Working - Root Cause Analysis & Fix Plan

## Problem Statement
Drag and drop functionality is not working in the Cosmo Symphony application. Users cannot drop video files or folders into the application to add them to the workspace.

## Root Cause Analysis

After examining the codebase, I've identified the following issues:

### 1. **Incorrect Tauri Event Listener API Usage** (PRIMARY ISSUE)
The code in `src/App.tsx` (line 667) uses:
```typescript
unlistenDragDrop = await win.onDragDropEvent(async (event: any) => { ... });
```

While `onDragDropEvent` is documented in Tauri v2, it may not be working correctly in version 2.10.3, or the event payload structure may differ from expectations. The more reliable approach that was documented in `DRAG_AND_DROP_SETUP.md` is to use the `listen` API:
```typescript
unlistenDrop = await win.listen('tauri://drag-drop', async (event) => { ... });
```

### 2. **Missing Separate Drag Enter/Leave Listeners**
The current code tries to handle all drag states (over, drop, leave) through `onDragDropEvent`, but the implementation may not be catching all events properly. The old code used separate listeners for `tauri://drag-enter` and `tauri://drag-leave` which is more reliable.

### 3. **Event Payload Structure Mismatch**
The code expects `event.payload.paths` and `event.payload.type`, but depending on the Tauri version, the payload structure might be different. The Rust enum shows:
```rust
pub enum DragDropEvent {
    Enter { paths: Vec<PathBuf>, position: PhysicalPosition<f64> },
    Over { position: PhysicalPosition<f64> },
    Drop { paths: Vec<PathBuf>, position: PhysicalPosition<f64> },
    Leave,
}
```

The `Enter` variant includes `paths`, but `Over` does not. The current code checks for `type === 'over'` to show the drag overlay, but if the payload doesn't have `paths` on `Enter`, it might fail.

### 4. **No Debug Logging**
There's no console logging to verify if the event listeners are being triggered, making it hard to diagnose.

## Solution Plan

### Fix 1: Replace `onDragDropEvent` with `listen` API
Use the standard event listener API that's documented and more reliable:

```typescript
// Replace the onDragDropEvent listener with:
let unlistenDrop: any;
let unlistenEnter: any;
let unlistenLeave: any;

const setupListeners = async () => {
  try {
    const win = getCurrentWindow();
    
    unlistenDrop = await win.listen('tauri://drag-drop', async (event: any) => {
      setDragFile(false);
      const paths = event.payload.paths;
      if (!paths || paths.length === 0) return;
      
      addLog(`System: Intercepting ${paths.length} drop assets...`);
      // ... rest of the drop handling logic
    });
    
    unlistenEnter = await win.listen('tauri://drag-enter', () => {
      console.log('Drag entered window');
      setDragFile(true);
    });
    
    unlistenLeave = await win.listen('tauri://drag-leave', () => {
      console.log('Drag left window');
      setDragFile(false);
    });
    
  } catch (err) { 
    console.error("Listener Setup Error:", err); 
  }
};
```

### Fix 2: Add Debug Logging
Add console.log statements to verify events are firing:
```typescript
unlistenDragDrop = await win.onDragDropEvent(async (event: any) => {
  console.log('DragDropEvent fired:', event);
  console.log('Event type:', event.payload?.type);
  console.log('Event paths:', event.payload?.paths);
  // ... rest of handler
});
```

### Fix 3: Verify Event Payload
Check if the payload structure matches expectations. If using `onDragDropEvent`, the payload should be directly accessible:
```typescript
// For onDragDropEvent, the event itself is the payload
console.log('Event:', event); // Should be { type: '...', paths: [...], position: {...} }
```

### Fix 4: Add Error Boundaries
Wrap the drag-drop setup in try-catch to log any initialization errors.

Replace the entire `setupListeners` function to use `listen` instead of `onDragDropEvent`:

```typescript
let unlistenDrop: any;
let unlistenEnter: any;
let unlistenLeave: any;

const setupListeners = async () => {
  try {
    const win = getCurrentWindow();
    
    unlistenDrop = await win.listen('tauri://drag-drop', async (event: any) => {
      console.log('Drag-drop event:', event);
      setDragFile(false);
      const paths = event.payload.paths;
      if (!paths || paths.length === 0) return;
      
      addLog(`System: Intercepting ${paths.length} drop assets...`);
      
      const validPaths = paths;
      const newVids: VideoItem[] = [];
      for (const path of validPaths) {
        try {
          let folderVids: { name: string, url: string }[] = [];
          try {
            folderVids = await invoke<{ name: string, url: string }[]>('get_folder_videos', { path, mode: mediaMode });
          } catch (e) {
            // Not a folder or backend error, proceed to file check
          }

          if (folderVids && folderVids.length > 0) {
            addLog(`Ingesting Set: ${path} (${folderVids.length} units)`);
            const folderWithUrls = folderVids.map(v => ({ 
              ...v, 
              url: toCosmoUrl(v.url),
              path: v.url
            }));
            newVids.push({ 
              id: crypto.randomUUID(), 
              url: folderWithUrls[0].url, 
              realPath: folderVids[0].url, 
              title: getFileNameFromPath(path) || 'Set', 
              repeatMode: 'folder', 
              repeatCount: 0, 
              cols: 1, 
              folderFiles: folderWithUrls, 
              currentIdx: 0, 
              playing: masterPlayingRef.current, 
              muted: masterMutedRef.current 
            });
            continue;
          }
          
          if (isValidMediaExtension(path, mediaMode)) {
            const lastSep = Math.max(path.lastIndexOf('\\'), path.lastIndexOf('/'));
            const parentPath = lastSep !== -1 ? path.substring(0, lastSep) : '.';
            let folderFiles: { name: string, url: string }[] = [];
            
            try {
              const siblings = await invoke<{ name: string, url: string }[]>('get_folder_videos', { path: parentPath, mode: mediaMode });
              if (siblings && siblings.length > 1) {
                folderFiles = siblings.map(v => ({ ...v, url: toCosmoUrl(v.url) }));
              }
            } catch (e) {
              console.warn("Could not fetch siblings:", e);
            }

            const filename = getFileNameFromPath(path);
            const currentIdx = folderFiles.findIndex(f => f.name === filename);

            newVids.push({ 
              id: crypto.randomUUID(), 
              url: toCosmoUrl(path), 
              realPath: path, 
              title: filename, 
              repeatMode: folderFiles.length > 0 ? 'folder' : 'none', 
              repeatCount: 0, 
              cols: 1, 
              folderFiles: folderFiles.length > 0 ? folderFiles : undefined,
              currentIdx: currentIdx !== -1 ? currentIdx : 0,
              playing: masterPlayingRef.current, 
              muted: masterMutedRef.current 
            });
          }
        } catch (err) { 
          console.error("Ingestion Error:", err); 
        }
      }
      
      if (newVids.length > 0) {
        setVideos(prev => [...prev, ...newVids]);
        addLog(`System: Successfully ingested ${newVids.length} units.`);
      }
    });
    
    unlistenEnter = await win.listen('tauri://drag-enter', () => {
      console.log('Drag entered');
      setDragFile(true);
    });
    
    unlistenLeave = await win.listen('tauri://drag-leave', () => {
      console.log('Drag left');
      setDragFile(false);
    });
    
  } catch (err) { 
    console.error("Listener Setup Error:", err); 
  }
};
```
