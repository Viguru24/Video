# Plan: Tauri Migration Refactoring & Feature Additions

## Summary
This plan addresses the refactoring and feature additions needed to complete the Tauri v2 migration for the Cosmo Video Symphony application. The changes extract inline UI components into dedicated modules and add a comprehensive Help system.

## Changes Overview

### 1. App.tsx (Refactoring + Bug Fixes)
- **Extract ControlBar**: Move inline header/control bar JSX into dedicated `ControlBar` component
- **Extract VideoGrid**: Move inline video grid rendering into dedicated `VideoGrid` component  
- **Add showHelp state**: New state for controlling Help modal visibility
- **Change default globalRepeat**: From `'none'` to `'always'` (videos auto-replay by default)
- **Change default repeatMode**: New videos use `'always'` instead of `'none'`
- **Sync play state on boot**: Persisted videos now sync `playing` state along with `muted` state

### 2. ControlBar.tsx (New Component)
- Extracted from App.tsx
- Contains all header controls: search, density slider, reset, folder add, auto-cycle, speed, play/pause, mute, volume, repeat, immersive toggle, settings
- Added **Help** button (replaces "Toggle UI" button)
- Added HelpModal integration
- Added `onMouseDown={(e) => e.stopPropagation()}` to slider inputs to prevent drag interference
- Properly passes all props through to App.tsx

### 3. VideoGrid.tsx (New Component)
- Extracted from App.tsx
- Handles DnD context and video grid rendering
- Includes both main grid and mini-map (rotating and static modes)
- Properly forwards all callbacks to video cards

### 4. HelpModal.tsx (New Component)
- Comprehensive help guide with three sections:
  - **Playback Capabilities**: Format support (native/legacy), HEVC power-up tip
  - **Keyboard Mastery**: All keyboard shortcuts (1-8 density, Space play/pause, F focus, S snapshot, ESC exit, Ctrl+Scroll density)
  - **Deep Interaction**: Double-click, right-click radial menu, drag & drop
- Styled with glassmorphism matching app theme

### 5. index.css (Style Additions)
- Added `--glass-deep` CSS variable
- Added extensive Help Modal styles:
  - `.help-modal` - modal container
  - `.format-grid` - format support grid
  - `.codec-pro-tip` - HEVC tip section
  - `.shortcut-grid` - keyboard shortcuts
  - `.interaction-list` - interaction guide
  - `.help-footer` - footer with version info
